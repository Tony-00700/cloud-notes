Supabase 연결

프로젝트 정보를 입력하면 notes 테이블과 실시간 동기화를 시작합니다.

로그인한 계정의 메모만 동기화됩니다. Publishable(Anon) Key를 입력하세요.

클라우드 계정으로 로그인하세요.

Supabase SQL Editor에서 실행할 테이블 SQL

create table public.notes (id uuid primary key default gen_random_uuid(), title text not null, content text not null default '', category text not null default '개인', created_at timestamptz not null default now());
alter table public.notes add column if not exists owner_id uuid not null default auth.uid();
alter table public.notes enable row level security;
create policy "notes_select_owner" on public.notes for select to authenticated using (auth.uid() = owner_id);
create policy "notes_insert_owner" on public.notes for insert to authenticated with check (auth.uid() = owner_id);
create policy "notes_update_owner" on public.notes for update to authenticated using (auth.uid() = owner_id) with check (auth.uid() = owner_id);
create policy "notes_delete_owner" on public.notes for delete to authenticated using (auth.uid() = owner_id);
alter publication supabase_realtime add table public.notes;

정책은 인증된 사용자가 본인 메모만 읽고 변경하도록 제한합니다.
