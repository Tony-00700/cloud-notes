Supabase 연결

프로젝트 정보를 입력하면 notes 테이블과 실시간 동기화를 시작합니다.

id, title, content, category, created_at 컬럼을 사용합니다. RLS 정책을 설정하세요.

Supabase SQL Editor에서 실행할 테이블 SQL

create table public.notes (id uuid primary key default gen_random_uuid(), title text not null, content text not null default '', category text not null default '개인', created_at timestamptz not null default now());
alter table public.notes enable row level security;
create policy "notes read" on public.notes for select using (true);
create policy "notes insert" on public.notes for insert with check (true);
create policy "notes update" on public.notes for update using (true) with check (true);
create policy "notes delete" on public.notes for delete using (true);
alter publication supabase_realtime add table public.notes;

예시는 공개 접근 정책입니다. 실제 서비스는 인증 및 사용자별 RLS 정책으로 교체하세요.
